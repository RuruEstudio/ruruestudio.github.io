Política de privacidad

Miss Tik · vigente desde el 11 de octubre de 2026

Quién la usa

Miss Tik es una asistente personal privada. La usa una sola persona, su dueño (Rurú, Ruru Estudio). No hay otros usuarios, no se ofrece al público y no tiene publicidad.

Qué datos de Google usa

  • Gmail (permiso gmail.modify): remitente, fecha, categoría, tamaño y etiquetas de los mails, para proponerle al dueño cómo ordenarlos. Solo con su aprobación etiqueta, archiva o manda a la papelera. No borra mails de forma definitiva (el permiso no lo permite). El contenido de un mail se lee solo si el dueño lo pide para ese mail.
  • Google Calendar (permiso calendar.events): ver y crear eventos del dueño.
  • Su dirección de correo (openid, email): para saber a qué cuenta corresponde cada permiso.

Dónde se guardan

El permiso y lo que Miss Tik anota viven en un teléfono del dueño, en un archivo privado, y en copias de respaldo cifradas en su computadora. No se suben a servidores propios ni de terceros.

Con quién se comparten

Con nadie. Los datos no se venden, no se usan para publicidad ni para entrenar modelos de inteligencia artificial propios. Cuando el dueño le pide a Miss Tik que lea o resuma un mail, ese texto se procesa con la API de Gemini de Google para generar la respuesta.

Uso limitado

El uso que Miss Tik hace de la información recibida de las APIs de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de Uso limitado.

Cómo quitar el permiso

En cualquier momento, desde myaccount.google.com/permissions → Miss Tik → Quitar acceso. Al quitarlo, Miss Tik deja de poder acceder a la cuenta y su archivo de permiso deja de servir.

English summary

Miss Tik is a private personal assistant used by a single person, its owner. With the owner's consent it reads Gmail metadata (sender, date, category, size, labels) to suggest how to organize the mailbox and, only with the owner's approval, labels, archives or moves messages to Trash; it never permanently deletes mail. It reads and creates Google Calendar events for the owner. Data is stored only on the owner's own devices, is never sold, shared or used for advertising. Message content is read only when the owner asks, and is then processed with Google's Gemini API to answer. Miss Tik's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
